Beispiele

cURL

curl "{{ base_url }}/api/steckbriefe?category=forschung&limit=10"

Python

import requests

response = requests.get(
    "{{ base_url }}/api/steckbriefe",
    params={"category": "forschung", "limit": 10}
)
data = response.json()

for steckbrief in data["steckbriefe"]:
    print(steckbrief["title"])

JavaScript

async function fetchSteckbriefe() {
    const response = await fetch(
        "{{ base_url }}/api/steckbriefe?category=forschung&limit=10"
    );
    const data = await response.json();

    data.steckbriefe.forEach(s => {
        console.log(s.title);
    });
}

fetchSteckbriefe();

Fehlerbehandlung

Die API verwendet Standard-HTTP-Statuscodes:

  • 200 OK - Erfolgreiche Anfrage
  • 400 Bad Request {{ i18n.api.error_400 | default('– Ungültige Parameter') }}
  • 404 Not Found {{ i18n.api.error_404 | default('– Ressource nicht gefunden') }}
  • 429 Too Many Requests {{ i18n.api.error_429 | default('– Rate Limit überschritten') }}
  • 500 Internal Server Error {{ i18n.api.error_500 | default('– Serverfehler') }}

{{ i18n.api.error_format | default('Format der Fehlerantwort') }}

{
  "error": {
    "code": "NOT_FOUND",
    "message": "Profile not found",
    "details": {}
  }
}
