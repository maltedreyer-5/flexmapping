| [installation.md](installation.md) | You are deploying it |

| [operations.md](operations.md) | It is running and you have a task to perform |
| [glossary.md](glossary.md) | A term in the interface is unfamiliar |
| [design/](design/) | You want to know why something is built the way it is |

Start with [features.md](features.md) if you are evaluating, with
[installation.md](installation.md) if you have already decided.
